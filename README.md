# 🎓 College Event Registration Form

A simple college event registration form built using HTML5.

## 📌 About the Project

This project is a practice project created while learning HTML forms and semantic HTML.

The form allows students to enter their personal information, select their course, choose their skills, upload a resume, and register for a college event.

## 🚀 Features

- Full Name input
- Email input
- Phone Number input
- Date of Birth
- Gender selection
- Course selection
- Skills selection using checkboxes
- Resume upload
- Address textarea
- Register button
- Reset/Clear button
- HTML form validation using `required`

## 🛠️ Technologies Used

- HTML5

## 📚 HTML Concepts Practiced

- Semantic HTML
- Forms
- Labels
- Input types
- Radio buttons
- Checkboxes
- Select and option
- Textarea
- File upload
- Buttons
- Form validation
- Fieldset and legend
